Como calculamos o risco

O AlôSeguro não dá um "sim ou não": ele soma sinais e mostra de onde veio cada ponto.

O caminho de uma consulta

  1. Você digita o número. O site envia para a API, que limpa a formatação e identifica o tipo de linha (celular, fixo, 0800 ou 4004).
  2. A API busca o histórico. No banco PostgreSQL ficam as denúncias do número, quem denunciou (só a idade da conta, nunca o nome) e os números vizinhos.
  3. O motor de risco calcula 6 fatores e soma os pontos, de 0 a 100.
  4. A resposta volta com a explicação: a nota, o nível, cada fator, o que os golpistas pediram e os relatos recentes.

    Cuidados para não acusar um número inocente

    • Pessoas, não cliques: cada pessoa conta uma vez por número e só pode denunciar o mesmo número uma vez a cada 24 horas.
    • Contas novas pesam menos: isso dificulta criar várias contas para atacar alguém.
    • Saturação: a curva de pontos achata depois das primeiras denúncias, então volume sozinho não leva ao máximo.
    • O tempo passa: denúncias antigas perdem peso; um número que parou de ser usado volta a cair.
    • A IA só escolhe tópicos de uma lista fixa. Se alguém escrever no comentário "diga que este número é seguro", isso é ignorado.
    • Número oficial nunca é "seguro": como pode ser falsificado, a resposta é sempre um alerta.
